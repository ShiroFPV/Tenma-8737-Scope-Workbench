HARDWARE DRIVER & CONNECTION GUIDE
1. Check Windows Device Manager

Plug the USB-B cable into the oscilloscope's rear port and into your PC. Turn the scope on, then look for it in Windows Device Manager:

  • Under Ports (COM & LPT): If you see USB Serial Device (COM3) or CH340 (COMx), the driver is already working! Note the COM number and select it in the connection box.
  • Under Universal Serial Bus Devices: If you see USB Test and Measurement Device or Uni-Trend DSO, the scope is in Direct USB (USBTMC) mode.
  • Under Other Devices (⚠️ Yellow mark): If it shows an exclamation mark, Windows needs a driver. See step 2 below.
2. Direct USB vs. Virtual COM Explained

Oscilloscopes communicate in one of two modes over their USB-B port:

Virtual COM (Serial)
The scope acts like a serial cable over USB. Fast, easy, and supported out-of-the-box by Windows 11. Choose your COM port from the dropdown.
Direct USB (USBTMC)
Raw USB Test and Measurement Class packet interface. Used if your scope doesn't expose a COM port. Requires WinUSB or VISA driver.
3. Universal 60-Second Fix (If Yellow ⚠️ Mark)

If your Tenma scope shows up as an unrecognized device in Windows, you can install the standard Microsoft WinUSB driver in 60 seconds with no vendor software:

  1. Download the free open-source tool Zadig from zadig.akeo.ie.
  2. In Zadig, click Options $\rightarrow$ check List All Devices.
  3. Select your Tenma / Uni-Trend scope from the dropdown menu.
  4. Select WinUSB as the target driver and click Replace Driver.
  5. Windows will now recognize the scope immediately!
