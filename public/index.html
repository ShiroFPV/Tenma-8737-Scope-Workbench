Windows 11 USB & COM Driver Reference
1. Restoring a WinUSB Device Back to a COM Port
Why WinUSB hides COM ports: WinUSB.sys is a raw USB bulk-transfer driver and does not create a serial COM interface. If WinUSB was installed (for example via Zadig), Windows moves the oscilloscope out of Ports (COM & LPT) and into Universal Serial Bus devices.

To restore Virtual COM:
1. Open Device Manager and expand Universal Serial Bus devices.
2. Right-click the device → Update driver → Browse my computer for drivers.
3. Select Let me pick from a list of available drivers on my computer.
4. Choose USB Serial Device (usbser.sys) and click Next.
5. If not listed, right-click → Uninstall device, check Attempt to remove the driver for this device, then reconnect the USB-B cable.
